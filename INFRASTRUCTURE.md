# 🏗️ Infrastructure Notes

## Services & Limits (Free Tier)

### Neon (PostgreSQL)
- **Plan**: Free
- **Storage**: 0.5 GB
- **Compute**: 0.25 vCPU, 1 GB RAM
- **Auto-pause**: After 5 days inactivity (auto-resumes on connection)
- **Dashboard**: https://console.neon.tech

### Render (FastAPI Backend)
- **Plan**: Free (Web Service)
- **RAM**: 512 MB
- **CPU**: Shared
- **Sleep**: After 15 min of no traffic (cold start: ~30–60s)
- **Dashboard**: https://dashboard.render.com
- **Service name**: `leadintel-backend`

### Vercel (React Frontend)
- **Plan**: Hobby (Free)
- **Bandwidth**: 100 GB/month
- **Builds**: Unlimited
- **Dashboard**: https://vercel.com/dashboard
- **Project**: `frontend`

## CORS Configuration

Backend (`main.py`) allows:
- `http://localhost:5173` (local dev)
- `http://127.0.0.1:5173` (local dev)
- Value of `FRONTEND_URL` env var (explicit Vercel URL)
- Any `https://*.vercel.app` subdomain (via `allow_origin_regex`)

---

## SPA Routing

`frontend/vercel.json` rewrites all routes to `index.html` so React Router handles navigation:

```json
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
```

## Database Schema

### `leads` table
| Column | Type | Notes |
|---|---|---|
| `id` | Integer PK | Auto-increment |
| `name` | String | Lead name |
| `email` | String | Nullable, unique |
| `company` | String | |
| `job_title` | String | |
| `location` | String | |
| `industry` | String | |
| `linkedin_url` | String | Unique |
| `status` | String | New / Contacted / Qualified / Rejected |
| `notes` | Text | Nullable |
| `created_at` | DateTime | UTC |

### `search_history` table
| Column | Type | Notes |
|---|---|---|
| `id` | Integer PK | Auto-increment |
| `user_query` | Text | Original user input |
| `filters_generated` | Text | Google search query generated by Gemini |
| `total_results` | Integer | Number of leads scraped |
| `created_at` | DateTime | UTC |

## API Endpoints

| Method | Path | Description |
|---|---|---|
| `GET` | `/health` | Health check + model info |
| `POST` | `/search-leads` | NL query → Apify scrape → DB store |
| `GET` | `/leads` | Paginated, filterable leads list |
| `PATCH` | `/leads/{id}` | Update status / notes |
| `GET` | `/download-leads` | Export leads as CSV |
| `POST` | `/generate-email` | AI cold email for a lead |
| `GET` | `/search-history` | Paginated search history |
